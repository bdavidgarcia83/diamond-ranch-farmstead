# Notes for maintaining this site

- Static site, no dependencies. `python3 build.py` renders `src/pages/*.html` through the layout in `build.py` into `_site/`. The GitHub Action passes the Pages base path as `SITE_BASE`; always link with `{{base}}` in page sources.
- Animals: `data/animals.json` only. Each gampr_parents entry generates /dogs/<slug>/ (gallery, summary, registration facts, Embark/OFA/Gampr.org links in a new window, 3-generation pedigree from the AGCA certificates; optional about paragraphs and a numbered journey with photos/video, used for Athena's import story). Dog cards on the Gampr page link only to these pages, never off-site. Toros and Athena have no OFA link yet: the AGCA profile shows Riley's OFA number on their entries. Listing pages show an empty-state message when a list is empty. `planned_litters` drives the planned-litter block on the Gampr page and the "Next planned litter" line on the home page.
- Forms post to FormSubmit (formsubmit.co) at the farm email; no key needed. The first submission triggers an activation email to that inbox.
- `site.json` `"preview": true` adds a banner, `noindex` and a disallow-all robots.txt. Set false at launch.
- Terms page: Gampr terms confirmed by owners ($3,200 with breeding rights; $2,500 without, rights later $700; $500 non-refundable deposit; balance 1 week before pickup; Zelle/CashApp/money order/cash only; return-to-seller; no outcrossing; buyer pays ground transport + CVI; no flying). Puppy/older-dog contract terms (AGCA membership, registration, vaccines, 8-week pickup, $75/wk boarding after 10 wks, genetic-fatal guarantee) are on the Terms page; Daisy's hip-remedy addendum is sale-specific and not published. Goats: $50 deposit, 50% refundable with an explanation, none for no-shows. No todo items remain; never invent policy.
- Never state facts about the animals (sex, ages, prices, test results) the owners haven't given.
- Design: colors come from the ranch logo (assets/img/logo-*.webp, source in Dropbox /Personal/Diamond Ranch Farmstead/Website/drflofo.jpg): sand bg, dark wood ink, rust accent. Rokkitt + Libre Franklin. Logo appears in header, hero, footer, favicon and og-image. Ranch silhouettes (assets/img/sil/, used as CSS masks via .sil classes) mark the home animal rows and walk along the footer ridge. Avoid cards/gradients.
- Eggs page (/eggs/, in nav): Delaware chickens; eating eggs and fertilized Delaware hatching eggs, $7/dozen eating eggs (pickup only), $2.50/egg hatching eggs (shipped, buyer pays). Shipping table is USPS Priority Mail retail estimates (fall 2026); refresh when USPS changes rates. Photos in assets/img/chickens.
- Sheep page (/sheep/): Dorper Katahdin cross (no set percentage), not for sale; keeping all ewe lambs to expand, rams raised for own use, ewes maybe in future (form collects interest). Photos in assets/img/sheep, video sheep-browse.mp4. The empty `sheep` list in animals.json is unused.
- Gampr puppy application (render_gampr_application) mirrors the owners placement questionnaire, minus names, prices and payment. AGCA lists us as Breeder of Merit.
- SEO: every page names the area (Hereford, near Sierra Vista; ~90 min from Tucson; southeast Arizona). LocalBusiness schema has areaServed. /gampr-guide/ is the breed guide (FAQ schema, linked from Gamprs page, home row and footer); keep breed facts sourced (IKU 2011 national dog, Armenian standard sizes).
- Ranch life page (/ranch-life/, in nav): guardians (Nilla, crossbred LGD, spayed), pets, horses and barn_cats in animals.json; photos and personality text still to come from the owners.
- Commit as small, plainly described changes; push to `main` publishes.
